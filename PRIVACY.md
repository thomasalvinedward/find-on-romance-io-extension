# Privacy

Find on Romance.io does not collect, transmit, sell, or analyze personal data.

When the button is clicked, the extension temporarily stores the current book title, author, source URL, and available retailer identifier in Chrome's local extension storage. That data is used only to carry the lookup from the retailer tab to the Romance.io search tab. It is deleted after the search is evaluated, and stale lookup records are automatically removed after one hour.

When the right-click selected-text search is used, the selected text is opened directly as a Romance.io search query. Selected-text searches do not create a temporary lookup record.

The extension contains no analytics, advertisements, tracking pixels, remote scripts, or backend service.
